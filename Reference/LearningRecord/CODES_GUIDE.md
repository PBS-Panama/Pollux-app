The code defines responsibilities for Company Security Officers, Ship Security Officers, and Port Facility Security Officers. It introduces three MARSEC levels that escalate operational security measures in response to changing threat environments. |

### Season 1 — Framework & History (order: 1)
> Context: The political and legal origins of ISPS, its structure, and the MARSEC level system.

| # | Title | Description |
|---|---|---|
| 1 | Why the ISPS Code Was Created | Post-9/11, IMO fast-tracked the International Ship and Port Facility Security Code (2002, in force 2004). The threat model — ship as weapon versus ship as target — drove the rapid drafting process, and the code was incorporated into SOLAS as the new Chapter XI-2. |
| 2 | ISPS Structure | The code is divided into Part A (mandatory requirements) and Part B (recommended guidance). The three key actors are the Company Security Officer (CSO), the Ship Security Officer (SSO), and the Port Facility Security Officer (PFSO), each with defined responsibilities. The Ship Security Plan (SSP) is the central operational document. |
| 3 | The Three MARSEC Levels | MARSEC 1 is the baseline normal level, MARSEC 2 is heightened, and MARSEC 3 is exceptional. The code defines who has authority to declare each level and what operational changes are required on the ship. Port States retain authority to set local MARSEC levels for vessels calling at their facilities. |

---

### Season 2 — Ship Security Officer Duties (order: 2)
> Context: Practical SSO responsibilities: the SSP, drills, access control, and threat recognition.

| # | Title | Description |
|---|---|---|
| 1 | The Ship Security Plan (SSP) | The SSP must contain provisions for restricted areas, security drills, training schedules, and security equipment maintenance. The plan is confidential — Port State Control officers may verify the ISSC and drill records but are not entitled to inspect the plan itself. |
| 2 | Security Drills and Exercises | Security drills must be conducted at least quarterly, with full exercises at least annually. A drill involves mustering security-sensitive crew and rehearsing response procedures, with all activity recorded in the Ship's Security Log. |
| 3 | Access Control and Visitor Management | Gangway access procedures must be adjusted at each MARSEC level, with increasing scrutiny of persons boarding. Identity verification uses seafarer's books, the ILO 185 Seafarer Identity Document, or biometric systems. Procedures for persons found on board without authorization must be included in the SSP. |
| 4 | Recognizing Security Threats | The SSO must be trained to identify suspicious behavior, waterside threats, and the distinction between stowaways and security threats. Unmanned craft approaching the vessel are a recognized threat vector. Escalation thresholds to the CSO and PFSO must be clearly defined. |

### Season 3 — Port Facility & Compliance (order: 3)
> Context: What the ship faces at the port side — DoS, ISSC, and non-compliant facilities.

| # | Title | Description |
|---|---|---|
| 1 | The Port Facility Security Plan | The ship's crew must understand what to expect at a compliant versus non-compliant port facility. The Declaration of Security (DoS) is a formal agreement between the ship and the port facility defining the security responsibilities each party will fulfill during the call. |
| 2 | International Ship Security Certificate (ISSC) | The ISSC is issued by the Flag State or a Recognized Security Organization (RSO) and is valid for five years with annual verification. An interim ISSC may be issued for new ships or ships changing flag. PSC inspectors verify the certificate and drill records, not the plan itself. |
| 3 | Non-Compliant Port Facilities | When a ship calls at a port without an approved port facility security plan, the master has defined obligations including notifying the Flag State and maintaining records of the circumstances. The code prescribes the minimum measures the ship must apply unilaterally in such situations. |

## SERIES 2 — IMDG CODE

| Field | Value |
|---|---|
| **Badge ID** | `imdg_code` |
| **Title** | IMDG Code |
| **Category** | Codes |
| **Description** | The International Maritime Dangerous Goods Code is the global rulebook for transporting dangerous goods in packaged form by sea, implementing SOLAS Chapter VII Part A. It classifies substances into nine hazard classes and assigns UN numbers, Proper Shipping Names, packing groups, stowage codes, and segregation requirements. The code is published biennially and the current edition must always be used on board. It covers the entire chain from classification and packaging through documentation, stowage, segregation, and emergency response. |

---

### Season 1 — Classification & Identification (order: 1)
> Context: How dangerous goods are classified, identified, and marked under the IMDG framework.

| # | Title | Description |
|---|---|---|
| 1 | What is the IMDG Code | The IMDG Code is the global standard for transporting dangerous goods in packaged form by sea, giving effect to SOLAS Chapter VII Part A. It is published biennially by IMO and the current edition is mandatory — using a superseded edition is a compliance failure. |
| 2 | The Nine Hazard Classes | The classes cover Explosives (1), Gases (2), Flammable Liquids (3), Flammable Solids and Substances (4), Oxidizers and Organic Peroxides (5), Toxic and Infectious Substances (6), Radioactive Materials (7), Corrosives (8), and Miscellaneous Dangerous Substances (9). Packing Groups I, II, and III indicate degree of hazard within a class. |
| 3 | UN Numbers and the Dangerous Goods List | Every dangerous substance is assigned a UN number that links to its Proper Shipping Name, hazard class, packing group, stowage code, and segregation group in the Dangerous Goods List. Volume 1 contains the general provisions and Volume 2 contains the DGL itself. |
| 4 | Markings, Labels, and Placards | A label is affixed to the package, markings include the UN number and Proper Shipping Name, and a placard is required on the cargo transport unit. Orientation arrows are required on certain packages. The "Marine Pollutant" mark applies to substances meeting that definition regardless of class. |

---

### Season 2 — Packaging, Documentation & Stowage (order: 2)
> Context: Getting the cargo properly packaged, documented, and placed on the ship.

| # | Title | Description |
|---|---|---|
| 1 | Packing Requirements | Packaging must meet UN specification standards validated by drop, leakproofness, and stack tests, with the results encoded in the UN packaging mark. Inner and outer packaging serve different functions, and performance packaging is distinguished from salvage packaging used for damaged cargo. |
| 2 | Dangerous Goods Documentation | The Dangerous Goods Declaration must be signed by the shipper and include all mandatory particulars. If the DGD is incorrect or missing, the master has the right — and obligation — to refuse the cargo. The Container Packing Certificate confirms the CTU was packed in accordance with the code. |
| 3 | Stowage Codes | IMDG stowage categories A through E define whether cargo may go on deck, under deck, or both, with Category A being the most permissive and Category D restricting cargo to on deck only. Special stowage provisions in column 16 of the DGL override or supplement the category. |
| 4 | Segregation | Dangerous goods must be kept apart from incompatible substances and from food, provisions, and living quarters. The four segregation terms — "away from," "separated from," "separated by a complete compartment," and "separated longitudinally" — represent increasing physical distances. The segregation table in the code cross-references all class combinations. |

---

### Season 3 — Emergency Response & Compliance (order: 3)
> Context: What to do when something goes wrong, and what PSC will check.

| # | Title | Description |
|---|---|---|
| 1 | Emergency Schedules (EmS) | The EmS Guide supplements the IMDG Code with fire schedules (F-schedules) and spillage schedules (S-schedules) linked to each substance. The schedule identifies immediate actions, protective equipment, first aid measures, and special precautions for each emergency type. |
| 2 | Medical First Aid Guide (MFAG) | The MFAG supplement provides medical treatment guidance for crew exposed to dangerous goods. Substances are cross-referenced to numbered treatment protocols covering decontamination, antidotes, and monitoring requirements for each category of exposure. |
| 3 | PSC Inspection and Compliance | Port State Control officers checking IMDG compliance will verify the accuracy of the dangerous goods declaration, correct segregation and stowage, proper placarding and marking, and stability documentation accounting for DG cargo. Common deficiencies include incorrect segregation and missing or inaccurate DGDs. |

## SERIES 3 — IMSBC CODE

| Field | Value |
|---|---|

| **Title** | IMSBC Code |
| **Category** | Codes |
| **Description** | The International Maritime Solid Bulk Cargoes Code has been mandatory since 2011 and governs all solid cargo transported in bulk, including coal, grain, ore, and nickel ore. It classifies cargoes into three groups: Group A (liquefaction risk), Group B (chemical hazard), and Group C (neither). The code places specific obligations on shippers to provide accurate declarations of cargo properties before loading. Failure to comply has been a contributing factor in multiple bulk carrier losses. |

### Season 1 — Solid Bulk Cargo Risks (order: 1)
> Context: How bulk cargoes are classified and what physical and chemical dangers they present.

| # | Title | Description |
|---|---|---|
| 1 | What is the IMSBC Code | The IMSBC Code became mandatory under SOLAS in 2011 and covers all solid cargo transported in bulk. The three cargo groups are A (liquefaction risk), B (chemical hazard), and C (neither), and determining the correct group for a cargo is the first step in compliance. |
| 2 | Group A Cargoes — Liquefaction Risk | Liquefaction occurs when cargo with high moisture content behaves like a liquid under vibration, causing catastrophic shifts in a ship's center of gravity. Affected cargoes include nickel ore, iron ore fines, and bauxite. The Transportable Moisture Limit (TML) must not be exceeded, and shippers must provide a Certificate of Moisture Content before loading. |
| 3 | Group B Cargoes — Chemical Hazards | Coal presents risks of oxygen depletion, methane emission, and spontaneous combustion requiring ventilation and gas monitoring. Sulfur produces toxic atmospheres. Direct Reduced Iron (DRI) reacts with moisture to produce hydrogen gas, creating a serious fire and explosion hazard. Each Group B cargo has specific testing, ventilation, and enclosed-space entry requirements. |

---

### Season 2 — Loading, Carriage & Compliance (order: 2)
> Context: The shipper's obligations, loading practice, and what PSC will find on deficient ships.

| # | Title | Description |
|---|---|---|
| 1 | Information Required Before Loading | The shipper must provide a declaration stating the cargo name, group classification, stowage factor, trimming requirements, and any special provisions. Cargoes not listed in the IMSBC Code require a special approval from the Flag State before loading. The master retains the right to refuse cargo if the declaration is inadequate. |
| 2 | Loading, Trimming, and Stowage | Proper trimming of bulk cargo is essential for both stability and prevention of cargo shifting. Group A cargoes have maximum permitted surface angle limits. Moisture content must be monitored throughout the voyage, and weather routing may be required to avoid conditions that accelerate liquefaction risk. |
| 3 | IMSBC and PSC | Common Port State Control deficiencies include loading without a proper shipper's declaration, absence of TML documentation, and failure to test for carbon monoxide or methane in holds carrying Group B cargoes. Carrying an unlisted cargo without Flag State approval is a serious violation. |

It applies to ships using LNG, methanol, or other alternative fuels with a flashpoint below 60°C. The code uses a goal-based approach combining prescriptive requirements with equivalency provisions. ---

### Season 1 — Gas as Fuel — Framework (order: 1)
> Context: The legal basis, risk philosophy, and crew certification requirements of the IGF Code.

| # | Title | Description |
|---|---|---|
| 1 | What is the IGF Code | The IGF Code entered into force in 2017 as a mandatory instrument under SOLAS Chapter II-1 Part G, applying to ships propelled by or using gas or other low-flashpoint fuels. It covers LNG, methanol, ethanol, and other qualifying fuels, establishing a framework that will evolve as alternative fuel technology matures. |
| 2 | Risk Control Concept | The code adopts a goal-based structure, meaning operators may propose equivalent solutions to prescriptive requirements provided the same safety level is demonstrated. The hazardous zone concept defines physical areas around gas fuel systems where ignition sources must be controlled. All safety systems must meet a single failure criterion — one failure must not cause a loss of safety function. |
| 3 | Crew Training Requirements | The STCW Manila Amendments introduced two levels: Basic Training for ships subject to the IGF Code (STCW Table A-V/3-1) covering awareness and emergency response, and Advanced Training (A-V/3-2) for officers with direct responsibility for gas fuel operations. Certificates must be held before serving on an IGF Code vessel. |

---

### Season 2 — Operations & Safety Systems (order: 2)
> Context: Bunkering, detection systems, and emergency response specific to LNG-fuelled vessels.

| # | Title | Description |
|---|---|---|
| 1 | LNG Bunkering Operations | LNG bunkering may be conducted ship-to-ship or shore-to-ship, and both require a pre-transfer conference to align procedures between the two parties. A safety zone must be established around the bunkering area and other vessels or ignition sources excluded. Emergency shutdown systems (ESD) must be installed and tested before each bunkering operation. |
| 2 | Gas Detection and Ventilation | Continuous fixed gas detection is required in all machinery spaces containing gas fuel equipment, supplemented by portable detectors for maintenance work. Ventilation systems must maintain safe atmospheres and are interlocked with alarm and automatic shutdown sequences. Alarm levels and shutdown thresholds must be clearly defined in the ship's procedures. |
| 3 | Emergency Procedures for LNG-Fuelled Ships | A fuel leak must trigger immediate isolation of the gas supply and activation of the ESD. The risk of a methane vapor cloud reaching an ignition source requires rapid area clearance. Cold gas equipment warming procedures must be followed before restarting. Emergency response for IGF Code vessels is integrated into the ship's overall ISM emergency plan. |

---

### Season 1 — Gas Carrier Types & Design (order: 1)
> Context: The IGC Code framework, the unique hazards of liquefied gas, and containment system design.

| # | Title | Description |
|---|---|---|
| 1 | What is the IGC Code | The IGC Code covers ships carrying liquefied gases in bulk, primarily LNG and LPG carriers. The four containment system types are membrane (including the GTT No. 96 and Mark III designs), Type A (self-supporting prismatic), Type B (spherical Moss), and Type C (pressure vessel). Each type has different structural philosophies and inspection requirements. |
| 2 | Hazards of Liquefied Gas Cargoes | LNG is carried at approximately -162°C, which causes brittle fracture in ordinary steel on contact. LPG is carried under pressure at ambient temperature with its own flammability and toxicity risks. Both cargoes have wide flammable ranges and present vapour cloud explosion potential. Rollover in LNG tanks — caused by density stratification — can release large volumes of vapour rapidly. |
| 3 | Cargo Containment Requirements | The cargo containment system must provide a primary and, where required, a secondary barrier to prevent cargo contact with the ship's hull. The IGC Code specifies minimum distances (J-distance) between the containment system and the ship's side. Hull steel must be selected for the minimum design temperature anticipated in case of cargo release. |

---

### Season 2 — Operations & Training (order: 2)
> Context: The cargo operation sequence, boil-off gas management, and STCW certification.

| # | Title | Description |
|---|---|---|
| 1 | Loading and Discharging LNG/LPG | Before loading LNG, tanks must be inerted, gassed-up with cargo vapour, and cooled down to near cargo temperature in a controlled sequence. Dew point monitoring during LNG loading prevents moisture contamination. Stripping and heel management ensures enough LNG remains to keep the tanks cold between voyages. |
| 2 | Boil-Off Gas Management | Natural boil-off from LNG tanks can be used as propulsion fuel, re-liquefied and returned to the cargo, or in older vessels vented through a gas combustion unit. The natural boil-off rate (NBOR) is a contracted performance parameter on LNG carriers. Forced vaporization systems apply to LPG carriers where vapour return to the terminal is required. |
| 3 | STCW Certification for Gas Tankers | STCW Table A-V/1-2 prescribes Basic Training for Liquefied Gas Tankers for all crew with designated safety duties on these vessels, and Advanced Training for officers in charge of cargo operations. The Gas Tanker Endorsement is added to the Certificate of Competency and must be verified by assessors before officers join a gas tanker. |

### Season 1 — Chemical Tanker Design (order: 1)
> Context: IBC Code structure, tanker type classification, and the Chapter 17 cargo assessment process.

| # | Title | Description |
|---|---|---|
| 1 | What is the IBC Code | The IBC Code governs ships carrying dangerous chemicals in bulk, defining three chemical tanker types based on the hazard level of permitted cargoes. A Type I ship has the highest level of damage survivability and may carry the most toxic or environmentally hazardous chemicals. The type designation is fixed at construction and determines what cargoes the ship is certificated to carry. |

Cross-contamination between cargo grades must be prevented through documented washing procedures, and clean tanks must be verified before loading to maintain Certificate of Fitness validity. |

### Season 2 — Operations & Safety (order: 2)
> Context: Pre-loading checks, chemical hazard identification, and STCW certification requirements.

| # | Title | Description |
|---|---|---|
| 1 | Chemical Cargo Operations | Pre-loading checks must confirm tank coating compatibility with the new cargo, compatibility with the previous cargo residue, and review of the chemical's Safety Data Sheet. Chemical tankers present more enclosed space entry risk than other vessel types due to the variety and toxicity of cargoes carried. |

## SERIES 7 — POLAR CODE

| Field | Value |

### Season 1 — Framework & Ice Classes (order: 1)
> Context: The Polar Code's legal basis, ship categories, key documents, and STCW requirements.

| # | Title | Description |
|---|---|---|
| 1 | What is the Polar Code | The Polar Code entered into force on 1 January 2017 for new ships and 1 January 2018 for existing ships, applying to both SOLAS and MARPOL vessels operating in Arctic and Antarctic waters. It supplements existing conventions rather than replacing them, adding polar-specific safety and environmental protection requirements. |
| 2 | Polar Ship Certificate and PWOM | Ships are assigned to Category A (capable of operating in at least medium first-year ice), Category B (medium first-year ice with some old ice inclusions), or Category C (designed for operation in open water or in ice conditions less severe than those of Category A and B). The Polar Water Operational Manual provides the ship-specific guidance for polar operations and must be approved by the Flag State. |
| 3 | STCW Polar Code Training | STCW regulation A-V/4 introduced Basic Training for ships operating in polar waters covering ice navigation awareness, cold weather survival, and emergency procedures, and Advanced Training for masters and officers in charge of the navigational watch on Category A and B ships. The level of training required depends on the ship category and the officer's role. |

---

### Season 2 — Navigation & Operations (order: 2)
> Context: Practical ice navigation, cold weather equipment management, and Arctic route planning.

| # | Title | Description |
|---|---|---|
| 1 | Ice Navigation | Sea ice is classified by type (first-year, multi-year), thickness, and concentration. Ice charts from national ice services and the POLARIS (Polar Operational Limit Assessment Risk Indexing System) method are used to assess whether a specific ship may safely transit a given ice regime. Icebergs present a separate hazard requiring radar watch and route deviation. |
| 2 | Cold Weather Operations | Hull icing increases topside weight and raises the ship's center of gravity, reducing stability. Machinery cold start procedures must address the effects of low temperatures on lubricants, hydraulics, and electrical systems. A crew member entering cold water in polar conditions has an extremely short survival time, making MOB in polar waters one of the most severe emergencies a ship can face. |
| 3 | Arctic Route Planning | The Northern Sea Route along the Russian Arctic coast and the Northwest Passage through the Canadian Archipelago are increasingly transited commercially. The PWOM must include voyage planning procedures addressing ice routing services, ice pilot requirements, and contingency plans. MARPOL Annex I has prohibited the use and carriage of heavy fuel oil as fuel in Arctic waters since July 2024, with phased waivers for certain ice-classed and flag-state-approved vessels until 2029. |

---

### Season 3 — Environmental Protection in Polar Waters (order: 3)
> Context: MARPOL obligations in polar waters, including the HFO ban and stricter discharge standards.

| # | Title | Description |
|---|---|---|
| 1 | MARPOL Annex I — Arctic HFO Ban | The 2021 MARPOL amendment banned the use and carriage of heavy fuel oil as fuel in Arctic waters, with full effect from July 2024. Ice-classed ships and vessels with flag-state approval may operate under waivers until July 2029. Operators must plan fuel changeovers and carry compliant fuel when entering the restricted area. |
| 2 | Discharge Restrictions in Polar Waters | MARPOL restrictions on oil, garbage, and sewage discharges are stricter in polar waters than in other areas, reflecting the ecological vulnerability of these regions. The Antarctic Treaty System imposes additional restrictions beyond MARPOL in the Antarctic Treaty Area, effectively prohibiting most discharges and requiring special waste management planning. |

### Season 1 — Life-Saving Appliances Standards (order: 1)
> Context: The LSA Code framework and the standards for personal life-saving appliances and distress equipment.

| # | Title | Description |
|---|---|---|
| 1 | What is the LSA Code | The LSA Code provides the technical specifications that give meaning to the SOLAS Chapter III requirement to carry "approved" life-saving appliances. It defines test methods, performance thresholds, required markings, and service life for every category of LSA, ensuring that equipment from different manufacturers performs consistently worldwide. |
| 2 | Personal Life-Saving Appliances | Adult lifejackets must provide a minimum of 150 N buoyancy (100 N for children), turn an unconscious person face-up within a defined time, and carry a light and whistle. Immersion suits must maintain body temperature in water for defined periods. Lifebuoys must be self-righting when thrown and the self-igniting light must activate automatically in water. |
| 3 | Pyrotechnics and EPIRB/SART | Parachute rocket flares, hand flares, and smoke signals must meet LSA Code performance standards and typically have a three-year service life after which they must be replaced. EPIRBs must be registered, have a valid battery and hydrostatic release, and transmit on 406 MHz to the COSPAS-SARSAT system. The SART radar transponder must operate for a minimum of 96 hours on standby. |

---

### Season 2 — Survival Craft & Rescue Boats (order: 2)
> Context: LSA standards for lifeboats, life rafts, and rescue boats.

| # | Title | Description |
|---|---|---|
| 1 | Lifeboat Standards | A totally enclosed lifeboat must achieve a minimum speed of 6 knots with its full complement and fuel for 24 hours, and must pass a self-righting test. The survival equipment inventory is prescribed by the LSA Code. Free-fall lifeboats have additional requirements for the deployment mechanism and the impact deceleration forces to which occupants may be subjected. |
| 2 | Life Raft Standards | SOLAS-approved inflatable life rafts have a maximum capacity of 25 persons and must be fitted with a hydrostatic release mechanism that activates automatically at a depth of 2 to 4 meters. SOLAS Pack A provides more comprehensive survival stores than Pack B and is required on ships making longer deep-sea voyages. Rigid life rafts are an alternative for specific vessel types. |
| 3 | Rescue Boat Requirements | A rescue boat must achieve a minimum speed of 6 knots with five persons on board and must be launchable by davit. SOLAS Regulation III/31 requires at least one rescue boat on every ship. Fast rescue boats (FRBs) capable of 8 knots or more are required on offshore platform support vessels and are specified separately from standard rescue boats. |

### Season 1 — Fire Safety Systems Standards (order: 1)
> Context: FSS Code scope, fire detection systems, and fixed gas extinguishing systems.

| # | Title | Description |
|---|---|---|
| 1 | What is the FSS Code | The FSS Code became mandatory on 1 July 2002 and provides the technical detail needed to implement the fire safety requirements of SOLAS Chapter II-2. | 3 | Fixed Gas Extinguishing Systems | CO₂ total flooding systems must deliver a design concentration of at least 34% by volume in the protected space. The system must trigger a minimum two-minute audible alarm before gas release to allow evacuation. Alternative systems including IG-55, IG-541, AFFF, and water mist systems are permitted when they can demonstrate equivalent extinguishing performance. |

| # | Title | Description |
|---|---|---|
| 1 | Portable Fire Extinguishers | FSS Chapter 4 prescribes extinguisher types, ratings, and placement. CO₂ extinguishers must be weighed annually, with a cylinder replacement threshold of 10% loss. > Context: The physics of cargo movement, the calculation methodology, and the Cargo Securing Manual.

| # | Title | Description |
|---|---|---|
| 1 | What is the CSS Code | The CSS Code provides practical guidance for the stowage and securing of cargo on ships other than bulk carriers and tankers. Although published as a non-mandatory IMO resolution, SOLAS Regulation VI/5 makes its calculation methodology the accepted standard, giving it de facto mandatory status for cargo securing assessments. |

### Season 2 — Lashing and Stowage Practice (order: 2)
> Context: Equipment ratings, container systems, and heavy lift and project cargo.

| # | Title | Description |
|---|---|---|

Vehicles on ro-ro ships are secured by wheel chocking plus lashing patterns, and the relevant SOLAS requirements under Regulation II-1/23 must be followed. The securing arrangement must be documented in the cargo plan. |

| # | Title | Description |
|---|---|---|
| 1 | What is the FAO/ILO/IMO Fishing Code | The Code of Safety for Fishermen and Fishing Vessels was developed jointly by FAO, ILO, and IMO to address the severe safety record of the global fishing fleet.
