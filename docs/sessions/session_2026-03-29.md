Board.js now checks role — company users get `CompanyHome` instead of the seafarer board.

**CompanyHome shows:**

**Archivos:**

New `GET /api/companies/{id}/vessels` endpoint. Auth-gated: only users belonging to the company can view its vessels.

**Archivos:**
- `backend/app/routers/companies.py` — new router
- `backend/app/main.py` — registered companies router

### 1.4 /me endpoint + localStorage — company_name

- `UserResponse` schema: added `company_name` field
- `/me` endpoint: JOINs Company table to return company name
- `LoginModal.tsx`: stores `role`, `company_id`, `company_name` in `leto-user`

**Archivos:**
- `backend/app/schemas/auth.py` — +company_name
