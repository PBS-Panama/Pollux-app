## Prioridad 1 — Ruta `/my-profile` (Vista de perfil propio del marino)

### Contexto

El dropdown del crewing module tiene un botón "Ver perfil completo" que actualmente manda al crew database (`#/company-crewdb`). El objetivo es que muestre una vista del **propio perfil del marino logueado**, similar a la pantalla MetaDetails (imagen de referencia: perfil con panel de documentos a la derecha).

**Por qué no se puede reusar MetaDetails directamente:**
- MetaDetails (`#/crew/{type}/{id}`) lee del catálogo Stremio — data estática de demo
- El usuario logueado vive en PostgreSQL + `crewing-api/users/{UUID}/`
- Son sistemas distintos — navegar a `#/crew/seafarer/{UUID}` resultaría en pantalla vacía

### Plan de implementación

#### Paso 1 — Nueva ruta en el router
Agregar la ruta `#/my-profile` en `src/App/routerViewsConfig.js` y `src/common/routesRegexp.js`.

```js
// routesRegexp.js — agregar entrada:
myprofile: {
    regexp: /^\/my-profile$/,
    urlParamsNames: []
},
```

```js
// routerViewsConfig.js — agregar:
{
    ...routesRegexp.myprofile,
    component: routes.MyProfile
}
```

## Prioridad 2 — Endpoint `/me` con rank y nombre

**Archivo:** `backend/app/routers/auth.py` + `backend/app/schemas/auth.py`

El endpoint `GET /api/auth/me` actualmente retorna solo `id, email, role, company_id, created_at`. El `rank`, `first_name` y `last_name` viven en la tabla `seafarers` (FK: `seafarers.id = users.id`).

**Fix:**
```python
# auth.py — endpoint /me
@router.get("/me", response_model=UserResponse)
def me(current_user: User = Depends(get_current_user), db: Session = Depends(get_db)):
    seafarer = db.query(Seafarer).filter(Seafarer.id == current_user.id).first()
    return {
        **current_user.__dict__,
        "rank": seafarer.rank if seafarer else None,
        "first_name": seafarer.first_name if seafarer else None,
        "last_name": seafarer.last_name if seafarer else None,
    }

# schemas/auth.py — UserResponse
class UserResponse(BaseModel):
    id: str
    email: str
    role: str
    company_id: Optional[str] = None
    created_at: datetime
    rank: Optional[str] = None           # ← agregar
    first_name: Optional[str] = None     # ← agregar
    last_name: Optional[str] = None      # ← agregar
```

Una vez hecho esto, `LoginModal.tsx` ya no necesita hacer el fetch separado a `/crewing-api/users/{id}/settings` para el rank — viene directo en el `/me`.
