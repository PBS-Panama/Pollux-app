### Architecture decisions
- **No Celery/Redis:** FastAPI `BackgroundTasks` satisfies the async requirement without new infrastructure
- **File access:** Backend fetches file bytes from castor via internal Docker URL: `http://castor:8080/users/{userId}/myfiles/download/{savedName}` (no auth needed — download endpoint is open)
- **`ai_verdict` already existed as JSONB** in Sprint 2 migration — only needed to add to `_DOC_SELECT` and `_doc_to_dict`
- **CAST(:exp AS jsonb) not ::jsonb:** SQLAlchemy named params use `:` prefix — `::jsonb` cast syntax creates a parse conflict. Fixed to `CAST(:exp AS jsonb)`.
- **MockOcrProvider is keyed by doc_key:** `_MockKeyedProvider` returns realistic text for Passport, Seaman's Book, CoC, etc. so classification demos work without a real Vision API key
- **Wrong document cascade:** when `ai_verdict.status === 'wrong_document'`, `verification_status` is also set to `wrong_document`. The VERIFY_BADGE already shows this state in the UI; the `AI_VERDICT_BADGE` shows the OCR origin.
- **Admin verdict override** (`PATCH /api/admin/documents/{doc_id}/verdict`): covers 4 target states: verified, rejected, pending, under_review

### Architecture decisions
- **No new deps:** Drive REST API implemented with `urllib.request` only. Token crypto via `cryptography.fernet` (already installed via `python-jose[cryptography]`).
- **OAuth state CSRF:** HMAC-SHA256 of `user_id` with `DRIVE_STATE_SECRET`. User ID embedded in state; verified on callback (no session needed).
- **Drive callback is unauthenticated:** OAuth callbacks can't carry a JWT. User ID comes from HMAC-verified state. After token exchange, server stores the encrypted refresh token in `drive_tokens`.
- **Import pipeline** reuses Obj.2 + Obj.3 infrastructure: castor multipart upload → FastAPI sync (generates code_name) → `analyze_document_background` BackgroundTask.
- **Backup** fetches physical files from castor via internal Docker network, creates `Leto Documents/{Rank}_{Name}_Dossier/{All Documents + category folders}/` structure in user's Drive.
- **Not-configured state:** When `GOOGLE_DRIVE_CLIENT_ID` env var is absent, all endpoints return `configured: false` / 400 errors. The UI shows setup instructions instead of a broken UI.

### Env vars needed for production
- `GOOGLE_DRIVE_CLIENT_ID` — GCP OAuth 2.0 client ID
- `GOOGLE_DRIVE_CLIENT_SECRET` — GCP OAuth 2.0 client secret
- `GOOGLE_DRIVE_REDIRECT_URI` — must match GCP console (default: `http://localhost:4000/api/drive/callback`)
- `DRIVE_TOKEN_SECRET` — secret for Fernet key derivation (32+ chars)
- `DRIVE_STATE_SECRET` — secret for HMAC state validation
