## BLOQUE 1 — SUPABASE SETUP (IDM)

**Responsable:** IDM
**Estimado:** 2–4 horas

### Tareas:
1. Crear proyecto en [supabase.com](https://supabase.com) (plan free es suficiente para el MVP)
2. Habilitar Google OAuth en `Authentication → Providers → Google`
   - Crear credenciales OAuth en [Google Cloud Console](https://console.cloud.google.com)
   - Authorized redirect URI: `https://<tu-proyecto>.supabase.co/auth/v1/callback`
3. Crear tabla `profiles` en Supabase (extiende la tabla `auth.users` automática):

```sql
CREATE TABLE profiles (
  id UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  role TEXT NOT NULL CHECK (role IN ('seafarer', 'company')),
  full_name TEXT,
  rank TEXT,                    -- solo seafarers
  company_name TEXT,            -- solo companies
  country TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- RLS: cada usuario solo ve su propio perfil
ALTER TABLE profiles ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users can view own profile" ON profiles
  FOR SELECT USING (auth.uid() = id);
CREATE POLICY "Users can update own profile" ON profiles
  FOR UPDATE USING (auth.uid() = id);
```

4. Crear tabla `vessels` (para el registro de empresa):

```sql
CREATE TABLE vessels (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  company_id UUID REFERENCES profiles(id) ON DELETE CASCADE,
  vessel_name TEXT NOT NULL,
  vessel_type TEXT,
  flag_state TEXT,
  imo_number TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

5. Entregar a Rick:
   - `SUPABASE_URL` (ej: `https://xxxx.supabase.co`)
   - `SUPABASE_ANON_KEY`
   - Confirmación de que Google OAuth está activo y funcional

### Modal 1: Iniciar Sesión

**Trigger:** Botón "Iniciar Sesión" (nav) y "Soy Empresa" (hero)

**Campos:**
- Email
- Password
- Botón: "Ingresar" → `supabase.auth.signInWithPassword()`

**Al autenticar exitosamente:**
1. Leer `profiles` para obtener `role`
2. Si `role === 'seafarer'` → redirigir a `/app/#/dashboard`

4. Si no existe perfil aún (primer login con Google) → abrir Modal de Rol

## BLOQUE 3 — SESIÓN PERSISTENTE (Rick)

Al cargar `index2.html`, verificar si hay sesión activa:
```js
const { data: { session } } = await supabase.auth.getSession();
if (session) {
  // Obtener rol y redirigir
  const { data: profile } = await supabase
    .from('profiles')
    .select('role')
    .eq('id', session.user.id)
    .single();

  if (profile?.role === 'seafarer') window.location = '/app/#/dashboard';
  if (profile?.role === 'company') window.location = '/app/#/company-dashboard';
}
```

También almacenar en `localStorage['leto-user']` para que el crewing module lo lea:
```js
localStorage.setItem('leto-user', JSON.stringify({
  id: session.user.id,
  email: session.user.email,
  role: profile.role,
  full_name: profile.full_name,
  rank: profile.rank || null,
  company_name: profile.company_name || null
}));
```
