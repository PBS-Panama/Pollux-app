## OBJETIVO

Eliminar la escritura dual de metadatos de documentos. Antes: Express escribía `data.json` Y disparaba sync fire-and-forget a FastAPI → desync silencioso posible. Después: Express = storage físico solamente; FastAPI/PostgreSQL = única fuente de verdad.

**Flujo target:**
```
Library.js → POST Express /upload → solo guarda archivo, devuelve { savedName, fileName, fileSize, mimeType }
           → await POST FastAPI /api/seafarer/me/documents/sync → devuelve doc completo con verification_status
Library.js reads everything → GET FastAPI /api/seafarer/me/documents  ← única fuente
```

## RESUMEN DE CAMBIOS

### Backend — `IDM/backend/app/main.py`
- Sprint 6A migrations: 7 nuevas columnas en `documents` (idempotent ALTER TABLE IF NOT EXISTS):
  - `file_name VARCHAR(500)`, `saved_name VARCHAR(500)`, `file_size INTEGER`, `mime_type VARCHAR(100)`
  - `category INTEGER`, `category_label VARCHAR(100)`, `validity_years INTEGER`

### Backend — `IDM/backend/app/routers/documents.py`
- **`_doc_to_dict(r)`**: helper que serializa todas las columnas del documento con aliases camelCase + snake_case
- **`_DOC_SELECT`**: constante SQL SELECT reutilizable con todas las columnas nuevas
- **`GET /seafarer/me/documents`**: ahora retorna `_doc_to_dict` con todos los campos (antes solo 10 campos, ahora 18)
- **`DocSyncPayload`**: extendido con `file_name`, `saved_name`, `file_size`, `mime_type`, `category`, `category_label`, `validity_years`
- **`POST /seafarer/me/documents/sync`**: 
  - UPSERT por nombre: UPDATE actualiza todos los campos incluyendo storage fields, resetea `verification_status = 'pending'`
  - INSERT nuevo registro con todos los campos de storage
  - Retorna el doc completo vía `_doc_to_dict` (antes devolvía `{id, created}`)
- **`PATCH /seafarer/me/documents/{doc_id}`** (nuevo): actualiza `issued_date` y `expiry_date`, retorna doc completo
- **`DELETE /seafarer/me/documents/{doc_id}`** (nuevo): self-service delete con ownership check (seafarer solo puede borrar sus propios docs)

### Express — `IDM/apiRoutes.js`
- Eliminado: `FASTAPI_BASE` constant y función `syncDocToFastapi` (fire-and-forget)
- Upload handler: eliminado `dm.addFileMetadata(userId, docMeta)` y `syncDocToFastapi(...)` call
- Upload handler: añadido `dm.ensureUserFolders(userId)` antes del save
- Upload response: cambió de `docMeta` (objeto completo) a `{savedName, fileName, fileSize, mimeType}` (solo storage)
- Nuevo endpoint: `DELETE /users/:userId/myfiles/file/:savedName` — rollback físico de archivo

### Crewing — `IDM/src/common/apiClient.js`
- **`getDocuments()`**: GET FastAPI `/api/seafarer/me/documents` con JWT — retorna array de docs completos
- **`uploadDocument(userId, file, docMeta)`**: 2-step awaitable:
  1. POST Express → `{savedName, fileName, fileSize, mimeType}`
  2. await POST FastAPI `/sync` → doc completo; si falla → DELETE físico en Express (rollback)
- **`updateDocumentDates(docId, dates)`**: PATCH FastAPI `/seafarer/me/documents/{docId}`
- **`deleteDocument(userId, docId, savedName)`**: DELETE FastAPI metadata + DELETE Express physical file

### Crewing — `IDM/src/routes/Library/useDocumentUpload.js`
- **Mount effect**: reemplazado `isApiAvailable()` + `getUploads()` por `getJwt()` check + `getDocuments()`; si hay JWT → modo API con FastAPI como fuente; `initUser()` se llama en background para garantizar carpetas Express
- **`addUpload()`**: usa `api.uploadDocument()` en lugar de `api.uploadFile()`, luego refresca con `api.getDocuments()`
- **`removeUpload(id)`**: dual-delete via `api.deleteDocument(userId, id, savedName)` (busca savedName en uploadedDocs state), luego refresca
- **Event listener** `pbs-uploads-changed`: refresca desde `api.getDocuments()` en lugar de `api.getUploads()`

### Crewing — `IDM/src/routes/Library/Library.js`
- **`verifyMap`**: eliminado state + useEffect separado que hacía fetch a FastAPI; reemplazado por `React.useMemo` derivado de `uploadedDocs` (la data ya viene con `verificationStatus` del GET)
- **`onSave`**: reemplazado `api.updateUploadMeta(api.DEFAULT_USER_ID, ...)` por `api.updateDocumentDates(selectedDocRecord.id, {issued_date, expiry_date})`; eliminada línea muerta `const result = await api.getUploads(...)`
