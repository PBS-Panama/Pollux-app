## FIX CRÍTICO — JSONB con psycopg2

**Problema:** `text("INSERT ... VALUES (:departments::jsonb ...")` lanza `SyntaxError` en psycopg2 porque `::` después de un parámetro se confunde con sintaxis psycopg2.

**Solución para INSERT:**
```python
from sqlalchemy import bindparam
from sqlalchemy.dialects.postgresql import JSONB

stmt = text("INSERT INTO ... VALUES (:departments ...)").bindparams(
    bindparam("departments", type_=JSONB)
)
db.execute(stmt, {"departments": python_list})  # pasar lista Python directamente
```

**Solución para UPDATE (PATCH dinámico):**
```python
import json as _json
# En el SET clause: "departments = :departments"
params["departments"] = _json.dumps(val)  # PostgreSQL castea text→jsonb implícitamente
```

**En WHERE clause** (`departments @> :dept::jsonb`) psycopg2 NO conflicta — solo falla en VALUES.
