## 1. User Database — Backend Infrastructure

Built a complete file-based database system with Express API endpoints.

### Folder Structure (auto-created per user)
```
User database/
  SF-001/                    # Hardcoded demo user (auth comes later)
    myfiles/
      data.json              # [{id, category, documentName, fileName, savedName, fileSize, mimeType, issuedDate, expiryDate, validityYears, status}]
      uploads/               # Actual uploaded files (PDFs, etc.)
    calendar/
      data.json              # {availability: [...], confirmedInterviews: [...]}
    dashboard/
      data.json              # {currentContract, rotationHistory, portCalls}
    myexams/
      data.json              # {bookedExams: [...]}
    settings/
      data.json              # {preferences: {}}
```

### New Backend Files
| File | Purpose |
|------|---------|
| `userDataManager.js` | Filesystem operations: auto-create folders, read/write JSON, file storage |
| `apiRoutes.js` | Express router with all CRUD endpoints for 5 pages |
| `http_server.js` | Updated: mounts API routes, body parser, multer for file uploads |

### API Endpoints
| Method | Endpoint | Purpose |
|--------|----------|---------|
| GET | `/api/users` | List all user IDs |
| POST | `/api/users/:id/init` | Create folder structure |
| GET | `/api/users/:id/:page` | Read page data (calendar, dashboard, myexams, settings) |
| PUT/PATCH | `/api/users/:id/:page` | Write/merge page data |
| POST | `/api/users/:id/myfiles/upload` | Upload file (multipart/form-data via multer) |
| GET | `/api/users/:id/myfiles/uploads` | List uploaded documents |
| PATCH | `/api/users/:id/myfiles/uploads/:docId` | Update document metadata (dates) |
| DELETE | `/api/users/:id/myfiles/uploads/:docId` | Delete file + metadata |
| GET | `/api/users/:id/myfiles/download/:savedName` | Download/preview a file |
| POST | `/api/users/:id/myfiles/rotate/:docId` | Rotate PDF pages (uses `pdf-lib`) |
| POST | `/api/users/:id/calendar/availability` | Add availability period |
| DELETE | `/api/users/:id/calendar/availability/:id` | Remove availability |
| POST | `/api/users/:id/calendar/confirm/:eventId` | Confirm interview |
| POST | `/api/users/:id/myexams/book` | Book an exam |
| DELETE | `/api/users/:id/myexams/book/:id` | Cancel exam booking |

### Frontend API Client

## 2. My Files Page (#/myfiles) — Complete Redesign

### Layout: 3-Column
```
CATEGORIES | DOCUMENT LIST (scrollable, filterable) | DATES + DROP ZONE + SAVE + PREVIEW
```

### Document Selector (Left Column, 20rem)
- **Search filter** input at top — type to filter across 83+ documents
- **Scrollable list** with all documents for the selected category
- **Green dot** next to documents that are already uploaded in the database
- **Green highlight** on selected document
- **Counter** at bottom: "83 documents — 5 uploaded"

### Upload Controls (Right Column)
- **Issue Date** + **Expiry Date** date pickers (appear when doc selected)
- **N/A button** for expiry — toggles "Does not expire" mode, saves `expiryDate: "N/A"`
- **Auto-computed expiry** — entering issue date auto-fills expiry based on known validity years
- **Drop zone** — "Drop your PDF file here / or click to browse" rectangle
- **Staged file** — file is held (green border, filename shown) until Save is clicked
- **SAVE TO DATABASE** button (green) — always available when doc selected:
  - New file + new doc → uploads file + metadata
  - New file + existing doc → replaces old file, uploads new one
  - No file + existing doc → updates dates only (upsert)
- **REMOVE** button (red) — appears only when selected doc has a file in DB
- **Success flash** — green confirmation bar for 3 seconds after save

### Preview Panel
- **Auto-shows** when selecting a document that has a file uploaded (green dot)
- Renders PDF in an iframe below the Save/Remove buttons
- **Edit button** (blue) opens rotate modal
- Uploaded documents list hides while preview is showing

### Rotate/Edit Modal
- Full-screen overlay (85vh height) with PDF preview
- **Rotate Left / Rotate Right** buttons with angle display (0°, +90°, etc.)
- Visual preview rotation via CSS transform before saving
- **Save Rotation** — applies rotation to actual PDF on server using `pdf-lib`
- Browser PDF toolbar hidden (`#toolbar=0`) to avoid confusion with built-in rotate
- **Cancel** or click outside to close

### Expiry Status Badges
- **Green** = Valid (>90 days remaining)
- **Amber** = Expiring Soon (≤90 days)
- **Red** = Expired
- **Gray** = No Expiry / Permanent

## 4. Stremio → Maritime Terminology Renaming

| Before (Stremio) | After (Maritime) | Files Changed |
|---|---|---|
| `?season=2` URL param | `?category=2` | `useSeason.js` → `useCategory` hook |
| `videoId` URL param | `documentId` | `routesRegexp.js`, `useMetaDetails.js`, `MetaDetails.js` |
| `SeasonsBar` component | `CategoryBar` | `SeasonsBar.js`, `SeasonsBarPlaceholder.js`, `SideDrawer.tsx` |
| `VideosList` component | `DocumentsList` | `VideosList.js`, `index.js` |
| `EpisodePicker` component | `DocumentPicker` | `EpisodePicker.tsx`, `index.ts` |
| `season`/`episode` props | `category`/`categories` | All above |
| `S2E3` display format | Document name + issued/expiry dates | `DocumentsList` |
| Route: `#/detail/movie/...` | Also accepts `#/crew/...` | `routesRegexp.js` |
